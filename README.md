# Turtleback Zoo Management System Application

## Project Overview

The **Turtleback Zoo Management System** course-project CS631 is an integrated application system is designed to facilitate efficient zoo management, streamline administrative tasks, and provide data-driven insights for decision-making.It includes three main applications: Asset Management, Daily Zoo Activity, and Management Reporting.

## Features

- **Asset Management**: Manage and track animals, buildings, attractions, and employees, including species details, locations, medical statuses, and specialized employee data.
- **Daily Zoo Activity**: Record daily attendance, track revenue from attractions, concessions, and ticket sales for adults, children, and seniors.
- **Management Reporting**: Generate detailed reports on daily/monthly revenue, animal population by species, medical costs, top revenue-generating attractions, and best revenue days.


## Technologies Used
- **Backend**: Spring Boot (Java)
- **Frontend**: Thymeleaf (for HTML rendering and user interface)
- **Database**: Oracle Database (for persistent data storage)
- **Development Tools**: IntelliJ IDEA, Maven, Git
